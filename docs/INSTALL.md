# การติดตั้ง

## รันบนเครื่องตัวเอง

```bash
cd โฟลเดอร์ที่แตกไฟล์ไว้
python3 -m http.server 8000
```

เปิด `http://localhost:8000` ถ้าไม่มี Python ใช้ `npx serve` หรือ `php -S localhost:8000` ก็ได้

**ทำไมเปิดไฟล์ตรง ๆ ไม่ได้** ตั้งแต่รอบที่ 8 ฐานข้อมูลยาถูกแยกไปอยู่ใน `data.json`
เบราว์เซอร์ทุกตัวบล็อกการอ่านไฟล์ข้างเคียงเมื่อเปิดผ่าน `file://` ด้วยเหตุผลด้านความปลอดภัย
ถ้าเปิดตรง ๆ แอปจะขึ้นหน้าจอบอกวิธีแก้ให้

## ขึ้น GitHub Pages

```bash
git init
git add .
git commit -m "iCareU"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/<ชื่อ repo>.git
git push -u origin main
```

ที่ repo ไปที่ **Settings → Pages** เลือก Source เป็น **Deploy from a branch**
branch `main` folder `/ (root)` แล้วกด Save
รอสักครู่จะได้ URL `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## ติดตั้งลงมือถือ

เปิด URL บนมือถือแล้วเลือกเพิ่มไปยังหน้าจอโฮม

- **iOS** ปุ่มแชร์ → Add to Home Screen
- **Android** เมนูสามจุด → ติดตั้งแอป

จะได้ไอคอน เปิดเต็มจอ และใช้งานออฟไลน์ได้เพราะ service worker แคชไฟล์ไว้ครบ

## ข้อมูลผูกกับที่อยู่เว็บ อ่านก่อนย้าย URL

นี่คือเรื่องสำคัญที่สุดของแอปนี้ ข้อมูลทั้งหมดเก็บอยู่ใน `localStorage` ของเบราว์เซอร์
ซึ่งผูกกับ **origin** คือ โพรโทคอล ชื่อโดเมน และพอร์ต ไม่ได้เก็บอยู่ในไฟล์หรือบนเซิร์ฟเวอร์

**ย้ายแล้วข้อมูลหาย** เมื่อเปลี่ยนอย่างใดอย่างหนึ่งต่อไปนี้

- เปลี่ยนโดเมน เช่น จาก `ชื่อผู้ใช้.github.io` ไปเป็นโดเมนของตัวเอง
- เปลี่ยนจาก `http` เป็น `https` หรือกลับกัน
- ย้ายจาก `localhost` ขึ้นเซิร์ฟเวอร์จริง
- เปิดคนละเบราว์เซอร์ หรือเปิดในเบราว์เซอร์ในแอปอื่น เช่น ในไลน์หรือเฟซบุ๊ก แทน Safari หรือ Chrome

**ย้ายแล้วข้อมูลไม่หาย** เปลี่ยนเฉพาะเส้นทางหลังโดเมน เช่น จาก `/app/` เป็น `/icareu/`
เพราะ `localStorage` มองที่ origin ไม่ได้มองเส้นทาง แต่ถ้าใช้ Service worker คนละ scope
อาจต้องกดรีเฟรชแรง ๆ หนึ่งครั้ง

### วิธีป้องกัน

1. **เลือก URL ให้จบตั้งแต่แรก** ถ้าจะใช้โดเมนของตัวเองให้ตั้งก่อนเริ่มกรอกข้อมูลจริง
2. **กดสำรองข้อมูลก่อนย้ายทุกครั้ง** ที่ ตั้งค่า → ข้อมูลของคุณ
   จะได้ไฟล์ `iCareU-backup-วันที่.json` ซึ่งมีทุกโปรไฟล์และประวัติทั้งหมด
   บนมือถือจะมีปุ่ม **ส่งไปเก็บที่ Drive หรือแอปอื่น** ซึ่งเปิดหน้าต่างแชร์ของเครื่อง
   เลือก Google Drive, iCloud Drive, Files หรือส่งเข้าไลน์ตัวเองก็ได้
   บนคอมพิวเตอร์ปุ่มนี้จะไม่ขึ้น ให้ใช้ปุ่มบันทึกไฟล์สำรองแทน
3. **แอปจะเตือนเองเมื่อไม่ได้สำรองเกิน 14 วัน** ขึ้นเป็นแถบเหลืองบนหน้าวันนี้ แตะแล้วได้ไฟล์เลย
4. **กู้ที่ URL ใหม่** เปิด URL ใหม่แล้วกดปุ่ม "เคยใช้มาก่อน กู้จากไฟล์สำรอง" บนหน้าแรก
   เลือกไฟล์ที่สำรองไว้ ข้อมูลจะกลับมาครบพร้อมรหัส PIN เดิม
5. **ติดตั้งเป็นแอปบนหน้าจอโฮม** แล้วแอปจะขอสิทธิ์ Persistent storage ให้อัตโนมัติ
   เบราว์เซอร์จะไม่ล้างข้อมูลนี้ทิ้งเองเมื่อพื้นที่ไม่พอ ดูสถานะได้ที่ ตั้งค่า → ข้อมูลของคุณ

### ตรวจว่าอยู่ที่เดิมหรือไม่
ที่ ตั้งค่า → ข้อมูลของคุณ มีบรรทัด "ที่อยู่เว็บของข้อมูลชุดนี้" บอก origin ปัจจุบัน
ในไฟล์สำรองก็มีฟิลด์ `origin` บันทึกไว้ว่าสำรองมาจากที่อยู่ไหน

### เก็บไฟล์สำรองไว้บนคลาวด์ของตัวเอง
แอปไม่มีเซิร์ฟเวอร์และไม่ได้ต่อกับบัญชีคลาวด์ใด ๆ โดยตรง แต่ใช้หน้าต่างแชร์ของเครื่องส่งไฟล์ออกไปได้
ทำให้เก็บไฟล์สำรองไว้ใน Google Drive หรือ iCloud ของคุณเองได้โดยแอปไม่ต้องรู้จักบัญชีคุณเลย

ตอนกู้ก็กดปุ่มนำไฟล์กลับเข้ามาหรือปุ่มบนหน้าแรก แล้วเลือกไฟล์จาก Drive ผ่านตัวเลือกไฟล์ของเครื่องได้
บน iPhone ต้องติดตั้งแอป Google Drive ไว้ก่อน Files ถึงจะเห็นโฟลเดอร์ Drive

ถ้าเปิดการเข้ารหัสไว้ ไฟล์ที่ส่งขึ้นคลาวด์เป็นฉบับเข้ารหัส
คนที่เข้าถึง Drive ได้จะเปิดไม่ออกถ้าไม่รู้รหัส PIN หรือคำตอบกู้รหัส
ถ้ายังไม่ได้เปิดการเข้ารหัส ไฟล์นั้นจะเป็นข้อความธรรมดา อ่านชื่อยาได้

### เรื่องเฉพาะของ iOS
Safari บน iOS จะล้างข้อมูลเว็บที่ไม่ได้เปิดเลยเป็นเวลา 7 วัน สำหรับเว็บที่ยังไม่ได้ติดตั้ง
ถ้าใช้ iPhone ให้ติดตั้งลงหน้าจอโฮมและเปิดใช้เป็นประจำ และสำรองไฟล์ไว้เป็นระยะ

## อัปเดตเวอร์ชันใหม่

แตกไฟล์ทับของเดิมได้เลย โครงสร้างเหมือนกันทุกไฟล์ ข้อมูลผู้ใช้อยู่ใน localStorage
ไม่ได้อยู่ในไฟล์ จึงไม่หาย

ทุกครั้งที่ปล่อยของใหม่ ให้เพิ่มเลขสองที่

```js
// sw.js
const CACHE = 'icareu-v17';    // เดิม v16

// index.html
const APP_VERSION = '22';      // เดิม 21
```

ผู้ใช้ที่เปิดแอปอยู่จะเห็นแถบ "มีเวอร์ชันใหม่พร้อมใช้งาน" ขึ้นมาเอง กดอัปเดตแล้วโหลดของใหม่ทันที
ข้อมูลใน `localStorage` ไม่หายเพราะไม่ได้อยู่ในแคช
ถ้าไม่กด ระบบจะถามใหม่ทุกครั้งที่กลับมาที่แอป และตรวจซ้ำทุก 30 นาที
ผู้ใช้กดตรวจเองได้ที่ ตั้งค่า → ข้อมูลของคุณ → ตรวจอัปเดต

## สิ่งที่ต้องมีเพื่อให้ฟีเจอร์ครบ

| ฟีเจอร์ | ต้องการ |
|---|---|
| ใช้งานทั่วไป | เว็บเซิร์ฟเวอร์ใด ๆ |
| ออฟไลน์และติดตั้งเป็นแอป | `https` หรือ `localhost` |
| การแจ้งเตือนของระบบ | `https` และผู้ใช้กดอนุญาต |
| เข้ารหัสข้อมูล | `https` (ใช้ Web Crypto) |
| ปลดล็อกด้วยใบหน้า | `https` และเป็นชื่อโดเมนจริง ไม่ใช่เลข IP |
