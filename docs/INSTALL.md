# การติดตั้ง

## รันบนเครื่องตัวเอง

```bash
cd โฟลเดอร์ที่แตกไฟล์ไว้
python3 -m http.server 8000
```

เปิด `http://localhost:8000` ถ้าไม่มี Python ใช้ `npx serve` หรือ `php -S localhost:8000` ก็ได้

**ทำไมเปิดไฟล์ตรง ๆ ไม่ได้** ตั้งแต่รอบที่ 8 ฐานข้อมูลยาถูกแยกไปอยู่ใน `data.json`
เบราว์เซอร์ทุกตัวบล็อกการอ่านไฟล์ข้างเคียงเมื่อเปิดผ่าน `file://` ด้วยเหตุผลด้านความปลอดภัย
ถ้าเปิดตรง ๆ แอปจะขึ้นหน้าจอบอกวิธีแก้ให้

## ขึ้น GitHub Pages

```bash
git init
git add .
git commit -m "ตารางยา"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/<ชื่อ repo>.git
git push -u origin main
```

ที่ repo ไปที่ **Settings → Pages** เลือก Source เป็น **Deploy from a branch**
branch `main` folder `/ (root)` แล้วกด Save
รอสักครู่จะได้ URL `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## ติดตั้งลงมือถือ

เปิด URL บนมือถือแล้วเลือกเพิ่มไปยังหน้าจอโฮม

- **iOS** ปุ่มแชร์ → Add to Home Screen
- **Android** เมนูสามจุด → ติดตั้งแอป

จะได้ไอคอน เปิดเต็มจอ และใช้งานออฟไลน์ได้เพราะ service worker แคชไฟล์ไว้ครบ

## อัปเดตเวอร์ชันใหม่

แตกไฟล์ทับของเดิมได้เลย โครงสร้างเหมือนกันทุกไฟล์ ข้อมูลผู้ใช้อยู่ใน localStorage
ไม่ได้อยู่ในไฟล์ จึงไม่หาย

ถ้าแก้ไฟล์แล้วเบราว์เซอร์ยังใช้ของเก่า ให้เพิ่มเลขเวอร์ชันใน `sw.js`

```js
const CACHE = 'medtrack-v4';   // เดิม v3
```

## สิ่งที่ต้องมีเพื่อให้ฟีเจอร์ครบ

| ฟีเจอร์ | ต้องการ |
|---|---|
| ใช้งานทั่วไป | เว็บเซิร์ฟเวอร์ใด ๆ |
| ออฟไลน์และติดตั้งเป็นแอป | `https` หรือ `localhost` |
| การแจ้งเตือนของระบบ | `https` และผู้ใช้กดอนุญาต |
| เข้ารหัสข้อมูล | `https` (ใช้ Web Crypto) |
| ปลดล็อกด้วยใบหน้า | `https` และเป็นชื่อโดเมนจริง ไม่ใช่เลข IP |
