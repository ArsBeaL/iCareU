# ตารางยา — บันทึกยาและอาหารเสริม

เว็บแอปสำหรับบันทึกยาและอาหารเสริมที่ต้องกินเป็นเวลา เตือนล่วงหน้าก่อนถึงเวลา
เตือนคู่ที่ไม่ควรกินร่วมกัน และคำนวณเพดานปริมาณต่อวันตามอายุ เพศ น้ำหนัก และส่วนสูง
ทำงานออฟไลน์ ข้อมูลอยู่ในเครื่องเท่านั้น ไม่มีเซิร์ฟเวอร์ ไม่มีบัญชีผู้ใช้
รองรับสองภาษา ไทยและอังกฤษ

design by Ars BeaL

## เริ่มใช้งานเร็วที่สุด

```bash
python3 -m http.server 8000
```

แล้วเปิด `http://localhost:8000` ในเบราว์เซอร์

> เปิดไฟล์ `index.html` ด้วยการดับเบิลคลิกจะใช้ไม่ได้ เพราะเบราว์เซอร์บล็อกการอ่าน `data.json`
> ที่อยู่ข้างเคียงเสมอ ต้องเปิดผ่านเว็บเซิร์ฟเวอร์

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ | ขนาด |
|---|---|---|
| `index.html` | ตัวแอปทั้งหมด HTML + CSS + JS | ~262 KB |
| `data.json` | ฐานข้อมูลยา ชื่อการค้า คู่ที่ห้ามกินร่วม และข้อมูลข้อห้าม | ~160 KB |
| `sw.js` | Service worker สำหรับใช้งานออฟไลน์ | 1 KB |
| `manifest.json` | ทำให้ติดตั้งลงหน้าจอโฮมได้ | 1 KB |
| `icon.svg` | ไอคอนแอป | 1 KB |

## ข้อความที่ต้องอ่านก่อนใช้จริง

แอปนี้ช่วยจำและช่วยเตือน **ไม่ใช่คำแนะนำทางการแพทย์**
ข้อมูลคู่ยาและเพดานปริมาณเป็นช่วงอ้างอิงจากตำรามาตรฐาน ไม่ครอบคลุมทุกกรณี
ก่อนเริ่ม หยุด หรือปรับยา ให้ปรึกษาแพทย์หรือเภสัชกรเสมอ
