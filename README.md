# ตารางยา — บันทึกยาและอาหารเสริม

เว็บแอปไฟล์เดียวสำหรับบันทึกยาและอาหารเสริมที่ต้องกินเป็นเวลา เตือนล่วงหน้าก่อนถึงเวลา
และเตือนเมื่อมีคู่ที่ไม่ควรกินพร้อมกัน ข้อมูลทั้งหมดเก็บใน `localStorage` ของเบราว์เซอร์
ไม่มีเซิร์ฟเวอร์ ไม่มีบัญชีผู้ใช้ ใช้งานออฟไลน์ได้

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด — HTML + CSS + JS ในไฟล์เดียว |
| `sw.js` | Service worker สำหรับแคชแอปให้เปิดได้ตอนออฟไลน์ |
| `manifest.json` | ทำให้ติดตั้งลงหน้าจอโฮมได้เหมือนแอปจริง |
| `icon.svg` | ไอคอนแอป |

## ขึ้น GitHub Pages

```bash
git init
git add index.html sw.js manifest.json icon.svg README.md
git commit -m "ตารางยา v1"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/<ชื่อ repo>.git
git push -u origin main
```

จากนั้นที่ repo ไปที่ **Settings → Pages** เลือก Source เป็น **Deploy from a branch**,
branch `main`, folder `/ (root)` แล้วกด Save รอสักครู่จะได้ URL
`https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

เปิด URL นั้นบนมือถือ แล้วเลือก **เพิ่มไปยังหน้าจอโฮม** (iOS: ปุ่มแชร์ → Add to Home Screen,
Android: เมนู → ติดตั้งแอป) จะได้ไอคอนและเปิดแบบเต็มจอ

> `sw.js` ทำงานเฉพาะบน `https://` หรือ `localhost` เท่านั้น เปิดจากไฟล์ `file://` โดยตรง
> แอปยังใช้ได้ครบทุกอย่าง แต่จะไม่มีการแคชและติดตั้งเป็นแอป

## สิ่งที่ทำได้

- **บันทึกรายการ** แยกยากับอาหารเสริม กำหนดขนาด ไอคอน และหลายเวลาต่อวัน
- **ความถี่** ทุกวัน / ระบุวันในสัปดาห์ / ระบุวันที่ของเดือน / เว้นวันทุก N วัน พร้อมวันเริ่มและวันสิ้นสุด
- **ความสัมพันธ์กับมื้ออาหาร** ก่อนอาหาร หลังอาหาร พร้อมอาหาร ท้องว่าง ก่อนนอน ระบุจำนวนนาทีห่างได้
- **เตือนล่วงหน้า** ตรงเวลา / 5 / 15 / 30 นาที ตั้งเป็นค่าเริ่มต้นรวม หรือแยกรายรายการก็ได้
  มีเสียง การสั่น การแจ้งเตือนของระบบ ปุ่มเลื่อน 10 นาที และเตือนซ้ำเมื่อเลยเวลา
- **ตรวจคู่ที่ห้ามกินร่วมกัน** ฐานข้อมูลในเครื่อง 24 กฎ ครอบคลุมสารและกลุ่มยา 40 รายการ
  ตรวจอัตโนมัติจากตารางเวลาจริง และเตือนซ้ำในหน้าต่างแจ้งเตือน
- **ค้นจาก openFDA** ดึงหัวข้อ Drug Interactions จากฉลากยาที่ขึ้นทะเบียนกับ U.S. FDA (ต้องต่อเน็ต)
- **ปฏิทินและสถิติ** ย้อนดูรายวัน พร้อมอัตราการกินครบ 7 / 30 / 90 วัน
- **นับจำนวนคงเหลือ** ตัดสต็อกอัตโนมัติเมื่อกด "กินแล้ว" และเตือนเมื่อใกล้หมด
- **โปรไฟล์หลายคน** แต่ละคนมีรายการ ประวัติ ธีม และรหัส PIN ของตัวเอง
- **ธีม 5 สี** ใบเตย คราม อบเชย อัญชัน บัว บวกโหมดกลางคืนและสีที่กำหนดเอง
- **สำรองและกู้คืน** ส่งออก/นำเข้าเป็นไฟล์ JSON

## ข้อควรรู้ก่อนใช้จริง

- **การเตือนทำงานเมื่อแอปเปิดค้างอยู่** เบราว์เซอร์ไม่อนุญาตให้เว็บตั้งนาฬิกาปลุกตอนปิดแท็บ
  ถ้าต้องการให้เตือนแน่นอน ให้ติดตั้งลงหน้าจอโฮมและเปิดค้างไว้เบื้องหลัง
- **รหัส PIN กันคนอื่นเปิดดู แต่ไม่ได้เข้ารหัสข้อมูล** ตัว PIN เก็บเป็นแฮช PBKDF2 120,000 รอบ
  ส่วนรายการยาเก็บเป็นข้อความธรรมดาใน localStorage ใครเข้าถึงเครื่องและเปิด DevTools ได้ก็อ่านได้
- **ลืม PIN แล้วกู้ไม่ได้** ทางเดียวคือกู้จากไฟล์สำรอง จึงควรกดสำรองไฟล์ไว้เป็นระยะ
- **ล้างข้อมูลเบราว์เซอร์แล้วข้อมูลหาย** localStorage ถูกลบไปด้วย
- **ไม่ใช่คำแนะนำทางการแพทย์** ฐานข้อมูลคู่ยาครอบคลุมเฉพาะคู่ที่พบบ่อยและมีเอกสารอ้างอิงชัดเจน
  ไม่ครอบคลุมทุกกรณี ก่อนเริ่ม หยุด หรือปรับยา ให้ปรึกษาแพทย์หรือเภสัชกรเสมอ

## โครงสร้างโค้ดโดยย่อ (สำหรับพัฒนาต่อ)

ทุกอย่างอยู่ใน `<script>` ท้าย `index.html` เรียงตามลำดับนี้

1. **ค่าคงที่** `TAGS` คือสารและกลุ่มยาพร้อม keyword ภาษาไทยและอังกฤษสำหรับเดาอัตโนมัติจากชื่อ
   `RULES` คือกฎคู่ยา แต่ละกฎมี `a`, `b` (รายการ tag), `sev` (`high`/`mod`/`low`/`good`),
   `gap` (นาทีที่ควรเว้น, 0 = ห้ามใช้ร่วมไม่ว่าจะเว้นเวลาแค่ไหน) และ `k:1` ถ้าเป็นข้อควรรู้เรื่องขนาดยา
   ที่ไม่ควรขึ้นเตือนบนรางเวลา
2. **ฐานข้อมูล** `DB` เก็บทุกโปรไฟล์ `P` คือโปรไฟล์ที่ใช้อยู่ บันทึกด้วย `save()`
   key ของ log คือ `YYYY-MM-DD|medId|HH:MM`
3. **ตารางเวลา** `isDue(med, dateStr)` ตัดสินว่าวันนั้นถึงกำหนดไหม `dosesFor(dateStr)` คืนรายการทั้งวัน
   `dayConflicts(doses)` หาคู่ที่ชนกันโดยดูระยะห่างเวลาจริงเทียบกับ `gap`
4. **หน้าจอ** `renderToday()` `renderMeds()` `renderCal()` `renderCheckPickers()` `renderSettings()`
   สลับหน้าด้วย `go(viewName)`
5. **การเตือน** `tick()` ทำงานทุก 15 วินาที ตรวจว่ามีรายการไหนถึงเวลาแล้วยังไม่บันทึก
   แล้วดันเข้า `alarmQueue` ให้ `showAlarm()` แสดงทีละอัน `P.notified` กันเตือนซ้ำ ล้างทุกวัน
6. **PIN** `hashPin()` ใช้ PBKDF2 ผ่าน Web Crypto มีทางสำรองเป็นแฮชธรรมดาถ้าเบราว์เซอร์ไม่รองรับ

### เพิ่มกฎคู่ยาใหม่

เพิ่มออบเจกต์ลงใน `RULES` ได้เลย ถ้าต้องใช้สารที่ยังไม่มีให้เพิ่มใน `TAGS` ก่อน

```js
{a:['zinc'], b:['calcium'], sev:'mod', gap:120,
 t:'หัวข้อสั้น ๆ',
 d:'อธิบายว่าเกิดอะไรขึ้นในร่างกาย',
 x:'ผู้ใช้ควรทำอย่างไร',
 s:'แหล่งอ้างอิง'}
```

## เพิ่มในรอบที่ 2

- **หน่วยแบบเลือก** ไม่ต้องพิมพ์เอง มี 15 รูปแบบ เม็ด แคปซูล ซอฟท์เจล ซอง ช้อนตวง มล. หยด พัฟ แผ่นแปะ ฯลฯ
- **ปริมาณตัวยาต่อ 1 หน่วย** พร้อมหน่วย มก. มคก. ก. IU มล. พันล้าน CFU mEq
  ระบบรวมยอดต่อวันข้ามทุกรายการที่มีสารเดียวกัน แล้วเทียบกับขีดสูงสุด 20 ค่า
  (Tolerable Upper Intake Level ของ NIH ODS และค่าจาก U.S. FDA) ขึ้นแถบเตือนเมื่อถึง 80% และเกิน 100%
- **หมวดและรายชื่อยา** 19 หมวด 179 รายการ เลือกแทนการพิมพ์ได้ กดแล้วเติมชื่อ ชื่ออังกฤษ สารสำคัญ หน่วย
  และขนาดมาตรฐานให้อัตโนมัติ อ้างอิงจากบัญชียาหลักแห่งชาติของ อย., WHO Model List of Essential Medicines
  และ NIH Office of Dietary Supplements
- **Tooltip รองรับมือถือ** แตะค้างไอคอนหรือป้ายใดก็ได้ราวครึ่งวินาที จะขึ้นคำอธิบายโดยไม่สั่งงานปุ่มนั้น
  บนเดสก์ท็อปใช้การชี้เมาส์และโฟกัสคีย์บอร์ด มีหน้า "คำอธิบายสัญลักษณ์" รวมทุกอันในหน้าตั้งค่า
- **ข้อมูลยารายหัวข้อ** 38 รายการ แยกเป็น ข้อบ่งใช้ / ข้อห้ามใช้ / คำเตือนและข้อควรระวัง /
  ผลข้างเคียงที่พบบ่อย / อาการที่ต้องหยุดยาและพบแพทย์ทันที เรียบเรียงจากฉลากยาของ U.S. FDA,
  เอกสารกำกับยาตามบัญชียาหลักแห่งชาติ และ NIH ODS พร้อมปุ่มดึงฉลากฉบับเต็มจาก openFDA
- **ข้อมูลร่างกาย** เพศ วันเกิด น้ำหนัก ส่วนสูง เก็บแยกรายโปรไฟล์ คำนวณอายุและ BMI
  และใช้ปรับขีดสูงสุดให้ตรงตัว เช่น พาราเซตามอลคิดที่ 15 มก./กก. ต่อครั้ง ไม่เกิน 4 ครั้งต่อวัน,
  แคลเซียมลดเหลือ 2,000 มก. เมื่ออายุ 51 ปีขึ้นไป
- **สองภาษา ไทย / อังกฤษ** สลับได้ในหน้าตั้งค่า จำค่าไว้รายโปรไฟล์

### ระบบสองภาษา

สลับได้ที่หน้าตั้งค่า จำค่าไว้รายโปรไฟล์ แปลครบทุกข้อความที่แอปเป็นเจ้าของแล้ว ทำงานสองชั้น

**ชั้นข้อมูล** เนื้อหาที่ยาวและมีผลต่อความปลอดภัย เขียนเป็นฟิลด์คู่ภาษาในตัวข้อมูลโดยตรง
ไม่ผ่านการแปลอัตโนมัติ ได้แก่ `RULES` 30 กฎ (`t` `d` `x` คู่กับ `te` `de` `xe`)
และ `INFO` 38 รายการ (`u` `c` `w` `s` `r` คู่กับ `ue` `ce` `we` `se` `re`)
เวลาแสดงผลใช้ตัวช่วย `RT(rule, field)` และ `IX(info, field)` เลือกฟิลด์ตามภาษาที่ตั้งไว้
ส่วนคำเชื่อมสั้น ๆ ที่ปนกับตัวเลขใช้ `Lx(ไทย, อังกฤษ)`

**ชั้นส่วนติดต่อผู้ใช้** ปุ่ม ป้าย หัวข้อ ข้อความแจ้งเตือน และ tooltip ใช้พจนานุกรม `DICT`
คู่กับ `PATT` สำหรับข้อความที่มีตัวเลขแทรก และ `MutationObserver` ที่แปลทุกอย่างที่เพิ่งวาดใหม่
คำแปลของชื่อสาร 40 รายการ ชื่อยา 179 รายการ วัน เดือน และหน่วย สร้างอัตโนมัติจากข้อมูลที่เป็นสองภาษาอยู่แล้ว
ด้วย `buildAutoDict()`

ตรวจความครอบคลุมด้วยการสลับเป็น English แล้วไล่ดูทุกหน้าและทุกแผ่นซ้อน
ผลล่าสุดเหลือข้อความไทยเฉพาะชื่อรายการที่ผู้ใช้พิมพ์เองเท่านั้น ซึ่งตั้งใจไม่แปล

### เพิ่มเนื้อหาใหม่ให้รองรับสองภาษา

- กฎคู่ยาใหม่ ใส่ `t` `d` `x` เป็นไทย แล้วเพิ่มคำแปลใน `RULES_EN` โดยใช้ข้อความของ `t` เป็นคีย์
- ข้อมูลยาใหม่ ใส่ใน `INFO` แล้วเพิ่มคำแปลใน `INFO_EN` โดยใช้ชื่อแท็กเป็นคีย์
- ข้อความ UI ใหม่ เพิ่มคู่ไทย-อังกฤษใน `DICT` ถ้ามีตัวเลขแทรกให้เพิ่มเป็น regex ใน `PATT`
- ยาในแคตตาล็อกและแท็กสารใหม่ ไม่ต้องทำอะไรเพิ่ม เพราะมีชื่ออังกฤษอยู่ในตัวข้อมูลแล้ว

## เพิ่มในรอบที่ 4 — แตะรายการแล้วเห็นคู่ห้ามกินและเพดานต่อวันทันที

แตะรายการใดก็ได้ ไม่ว่าจะเป็นไอคอนยาบนรางเวลา ปุ่ม ⓘ ในหน้ารายการ หรือแตะชื่อยาในหมวด
จะเปิดแผ่นข้อมูลที่ขึ้นสองบล็อกนี้ไว้บนสุดก่อนเนื้อหาอื่น

### บล็อก "ห้ามกินคู่กับ"
ไล่ `RULES` ทั้งหมดหาสารที่ชนกับรายการนี้ แล้วแสดงเป็นรายการเรียงตามความรุนแรง
ห้ามกินพร้อมกัน ต้องเว้นระยะ ระวัง และปิดท้ายด้วยคู่ที่กินร่วมแล้วดี
แต่ละคู่บอกว่าเกิดอะไรขึ้น ต้องทำอย่างไร และต้องห่างกันกี่ชั่วโมง
ถ้าคู่นั้นอยู่ในรายการของคุณอยู่แล้ว จะมีแถบแดงขึ้นบนสุดบอกชื่อรายการนั้นตรง ๆ

### บล็อก "ห้ามกินเกินวันละเท่าไร"
คำนวณจากข้อมูลร่างกายในโปรไฟล์ แล้วบอกเพดานเป็นตัวเลขเดียวชัด ๆ พร้อมเหตุผลว่าปรับมาจากอะไร

- **อายุ** ใช้ตาราง Tolerable Upper Intake Level แยกช่วงอายุของ NIH ODS ครบ 15 สาร
  เช่น แคลเซียม 9–18 ปีได้ถึง 3,000 มก. แต่ 51 ปีขึ้นไปเหลือ 2,000 มก.
- **น้ำหนัก** ยาที่คิดตามน้ำหนักใช้สูตรของ อย. พาราเซตามอล 10–15 มก. ต่อกิโลกรัมต่อครั้ง
  ไม่เกินวันละ 4 ครั้ง แปลงเป็นจำนวนเม็ดให้เลย เช่น 52 กก. ได้ครั้งละ 780 มก. หรือราว 1.5 เม็ดของ 500 มก.
  ซึ่งตรงกับตารางกินยาพาราตามน้ำหนักของ อย. (34–50 กก. 1 เม็ด, 51–67 กก. 1.5 เม็ด, 68 กก. ขึ้นไป 2 เม็ด)
- **เพศและการตั้งครรภ์** โปรไฟล์ที่ระบุเพศหญิงจะมีสวิตช์ "กำลังตั้งครรภ์" เพิ่มมา
  เมื่อเปิดจะลดเพดานคาเฟอีนเหลือ 200 มก. ต่อวัน และขึ้นคำเตือนเรื่องวิตามินเอรูปเรตินอลกับยากลุ่ม NSAIDs
  ส่วนผู้หญิงวัยมีประจำเดือนจะมีหมายเหตุเรื่องความต้องการธาตุเหล็กที่สูงกว่าผู้ชาย
- **ค่าอ้างอิงไทย** แสดง Thai RDI จากประกาศกระทรวงสาธารณสุขว่าด้วยฉลากโภชนาการ 19 สาร
  เป็นค่า "ควรได้รับต่อวัน" คู่กับเพดาน "ไม่ควรเกิน" เพื่อให้เห็นทั้งสองฝั่ง
- **ยอดจริงของคุณ** ถ้ารายการในตารางกรอกปริมาณต่อหน่วยไว้ จะมีแถบและเปอร์เซ็นต์บอกว่าวันนี้ได้รับไปแล้วเท่าไรของเพดาน

ตารางที่ใช้อยู่ในตัวแปร `UL_AGE` (ขีดสูงสุดตามอายุ), `THAI_RDI` (ค่าฉลากไทย)
และ `WEIGHT_DOSE` (ยาที่คิดตามน้ำหนัก) ฟังก์ชัน `limitFor(tag)` เป็นตัวรวมทุกเงื่อนไข
ส่วน `pairsFor(tags)` และ `myConflicts(tags)` สร้างรายการคู่ที่ห้ามกินร่วม

### หมายเหตุที่แสดงในแอปเสมอ
ค่าทั้งหมดเป็นเพดานสำหรับคนทั่วไปที่สุขภาพแข็งแรง ผู้ที่มีโรคไต โรคตับ หรือกำลังตั้งครรภ์
ต้องใช้ค่าที่แพทย์กำหนดแทน และถ้าแพทย์สั่งให้กินเกินค่านี้ ให้ทำตามแพทย์

## เพิ่มในรอบที่ 5 — ยาเด็กและขนาดตามน้ำหนักแบบเต็มรูปแบบ

ไม่ได้มีแค่พาราเซตามอลกับไอบูโพรเฟน การคิดขนาดยาตามน้ำหนักตัวเป็นมาตรฐานของยาเด็กแทบทุกชนิด
รอบนี้เพิ่มเป็น 14 ตัวยาที่คิดตามน้ำหนัก และ 2 ตัวที่คิดตามอายุ

**คิดตามน้ำหนัก (`WEIGHT_DOSE`)** พาราเซตามอล, ไอบูโพรเฟน, อะม็อกซีซิลลิน, เซฟาเล็กซิน, เซฟิซิม,
ไดคล็อกซาซิลลิน, อะซิโทรมัยซินและกลุ่มแมโครไลด์, โคไตรม็อกซาโซล (คิดตามส่วนไตรเมโทพริม),
เมโทรนิดาโซล, คลอร์เฟนิรามีน, เพรดนิโซโลน, ซาลบูทามอลชนิดกิน, ฟูโรซีไมด์
และธาตุเหล็กขนาดรักษาภาวะโลหิตจาง

รองรับทั้งสองแบบที่ตำรายาใช้จริง คือคิดต่อครั้ง (mg/kg/dose) และคิดต่อวันแล้วหารเป็นมื้อ (mg/kg/day)
ผลลัพธ์แสดงเป็นช่วง ครั้งละเท่าไร กี่ครั้งต่อวัน รวมต่อวันไม่เกินเท่าไร
พร้อมแปลงเป็นจำนวนมิลลิลิตรของยาน้ำที่พบบ่อยและจำนวนเม็ด
เศษที่ต่ำกว่าครึ่งเม็ดจะไม่แสดงเป็นเม็ดเพราะแบ่งจริงไม่ได้ ให้ใช้ยาน้ำแทน

**คิดตามอายุ (`AGE_DOSE`)** อัลเบนดาโซลถ่ายพยาธิ และสังกะสีสำหรับเด็กท้องเสียตามคำแนะนำ WHO/UNICEF

**คำเตือนเฉพาะเด็ก (`CHILD_WARN`)** แสดงอัตโนมัติเมื่อโปรไฟล์อายุต่ำกว่า 18 ปี เช่น
ห้ามให้แอสไพรินแก่เด็กที่มีไข้จากไวรัสเพราะเสี่ยงกลุ่มอาการเรย์,
เตตราไซคลินห้ามใช้ต่ำกว่า 8 ปี, โคไตรม็อกซาโซลห้ามใช้ในทารกต่ำกว่า 2 เดือน

**ส่วนสูงถูกใช้จริงแล้ว** คำนวณพื้นที่ผิวกายด้วยสูตร Mosteller แสดงคู่กับอายุ เพศ น้ำหนัก
บนหัวบล็อก และยังใช้คำนวณ BMI เหมือนเดิม

**คู่ที่ห้ามกินร่วมเพิ่มอีก 7 กฎ** เมโทรนิดาโซลกับแอลกอฮอล์, ยาปฏิชีวนะกลุ่มแมโครไลด์
โคไตรม็อกซาโซลและเมโทรนิดาโซลกับวาร์ฟาริน, โคไตรม็อกซาโซลกับยาความดันที่ทำให้โพแทสเซียมสูง,
แมโครไลด์กับสแตติน, เบต้าบล็อกเกอร์กับยาขยายหลอดลม และ NSAIDs กับยาขับปัสสาวะกลุ่มลูป
พร้อมหมวดใหม่ในแคตตาล็อก "ยาน้ำสำหรับเด็ก" 18 รายการ

แหล่งอ้างอิงเพิ่มเติมของรอบนี้ WHO Pocket Book of Hospital Care for Children,
WHO/UNICEF Joint Statement on the Clinical Management of Acute Diarrhoea,
WHO Preventive chemotherapy for soil-transmitted helminths และฉลากยาของ U.S. FDA แต่ละตัว

## เพิ่มในรอบที่ 6 — การซูม รหัส PIN และการปลดล็อกด้วยใบหน้า

### กันการซูมจากการแตะรัว
สาเหตุคือ double-tap zoom ของเบราว์เซอร์บนมือถือ แก้สามชั้น

- `<meta name="viewport">` เพิ่ม `maximum-scale=1, user-scalable=no`
- CSS `touch-action: manipulation` ที่ `html` และที่ปุ่มทุกชนิด ซึ่งเป็นตัวปิด double-tap zoom โดยตรง
  และยังตัดดีเลย์ 300 มิลลิวินาทีของการแตะ ทำให้ปุ่มตอบไวขึ้นด้วย
- `-webkit-text-size-adjust: 100%` กันไม่ให้ตัวอักษรถูกขยายเองตอนหมุนจอ

ข้อควรทราบ iOS Safari ตั้งแต่เวอร์ชัน 10 เป็นต้นมาไม่สนใจ `user-scalable=no` โดยเจตนา
เพื่อไม่ให้เว็บปิดการซูมของผู้ใช้สายตาไม่ดี บน iPhone จึงยังบีบนิ้วซูมได้อยู่
แต่ `touch-action: manipulation` ทำงานทุกเบราว์เซอร์ ซึ่งแก้อาการ "แตะรัวแล้วจอเด้ง" ได้ตรงจุดที่สุด

### รหัส PIN แสดงให้ตรงกับที่ต้องใส่
เดิมข้อความบอก 4–6 หลัก แต่โค้ดรอถึง 6 หลักถึงจะส่งเอง เป็นบั๊กที่ทำให้สับสน ตอนนี้เปลี่ยนเป็น

- หน้าตั้งรหัสมีปุ่มเลือก **4 หลัก / 6 หลัก** ชัดเจน ค่าเริ่มต้นคือ 6 หลัก
- จำนวนจุดบนหน้าจอเท่ากับจำนวนหลักที่เลือกเสมอ และข้อความเปลี่ยนตามทันที
- ครบตามจำนวนแล้วระบบส่งเอง ไม่ต้องกดตกลง
- ตอนยืนยันซ้ำ ระบบล็อกจำนวนหลักให้เท่ากับรอบแรก ถ้าไม่ตรงกันจะกลับไปให้เลือกใหม่
- หน้าปลดล็อกอ่านค่า `pinLen` ของโปรไฟล์ แล้ววาดจุดกับส่งอัตโนมัติตามจำนวนนั้น

### ปลดล็อกด้วยใบหน้าหรือลายนิ้วมือ
ใช้ **WebAuthn platform authenticator** ซึ่งคือ Face ID บน iPhone, ลายนิ้วมือบน Android
และ Windows Hello บนคอมพิวเตอร์ ไม่ได้ใช้กล้องสแกนหน้าเอง เพราะการเทียบภาพหน้าในเว็บ
หลอกด้วยรูปถ่ายได้และไม่ปลอดภัยพอจะใช้เป็นรหัสผ่าน

เปิดใช้ที่ ตั้งค่า → ความปลอดภัย → ปลดล็อกด้วยใบหน้าหรือลายนิ้วมือ
เมื่อเปิดแล้ว หน้าล็อกจะเรียกการยืนยันตัวตนให้อัตโนมัติหนึ่งครั้ง และมีปุ่มให้กดซ้ำได้
รหัส PIN ยังใช้ได้เสมอในฐานะทางสำรอง

**เงื่อนไขที่ต้องมี**

- ต้องเปิดผ่าน `https` และเป็นชื่อโดเมนจริง GitHub Pages ใช้ได้ แต่เลข IP หรือเปิดไฟล์ตรง ๆ ใช้ไม่ได้
- อุปกรณ์ต้องตั้ง Face ID ลายนิ้วมือ หรือ Windows Hello ไว้ก่อน
- กุญแจผูกกับโดเมนและเครื่องนั้น ย้ายเครื่องหรือเปลี่ยนโดเมนต้องตั้งใหม่

**สิ่งที่มันทำและไม่ทำ** แอปนี้ไม่มีเซิร์ฟเวอร์ จึงตรวจลายเซ็นแบบที่ระบบ WebAuthn เต็มรูปแบบทำไม่ได้
คุณค่าจริงคือระบบปฏิบัติการยืนยันตัวผู้ใช้ให้ก่อนปล่อยผ่าน ซึ่งเทียบเท่ากับการกดรหัส PIN ถูก
ไม่ได้เพิ่มการเข้ารหัสข้อมูล ตัวรายการยายังเก็บเป็นข้อความธรรมดาใน localStorage เหมือนเดิม
ถ้าต้องการความปลอดภัยระดับเข้ารหัสจริง ต้องแลกกับการที่ลืมรหัสแล้วข้อมูลหายถาวร
